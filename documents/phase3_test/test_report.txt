5. Placeholder validation
-------------------------
After substitution the CV template still contained a number of LaTeX control
sequences and bracket‑based placeholders that are part of the original template
(e.g. \section, \begin{itemize}, \cventry, etc.).  These are not user‑visible
placeholders and are expected; the script only replaced the four personal‑data
lines.  No remaining "[First]" "[Last]" etc. were found.

6. PDF verification status
-------------------------
- LaTeX (lualatex / xelatex) is not installed in the current environment,
  so the generated .tex files cannot be compiled to PDF within this session.
- pypdf is available and can extract text from PDFs, but no PDFs exist yet.
- Layout verification (verify_layout.py) requires pdftotext -bbox, which is also
  absent; it would report “skipped” (degraded mode).
- Consequently, PDF page‑count and layout checks are marked as **unavailable** for
  this run.  The user will need a LaTeX distribution and Poppler to perform
  full PDF verification.
